# 🚀 TaskFlow – Smart Task Management System

TaskFlow is a modern, multi-user task management web application built using **HTML, CSS, and JavaScript**.  
It helps users manage daily tasks efficiently with a clean UI and powerful productivity features.

---

## ✨ Features

### 🔐 User System
- Register & Login functionality
- Each user has separate task data
- Data stored securely using LocalStorage

### ✅ Task Management
- Add, complete, and track tasks
- Priority levels (High / Medium / Low)
- Due date tracking with countdown
- Progress tracking bar

### 📊 Dashboard Analytics
- Live task statistics (Total / Completed / Pending)
- Interactive donut progress chart

### 🗂 Kanban Board
- Trello-style task board
- Drag and drop tasks between:
  - Todo
  - In Progress
  - Completed

### 🌙 Dark Mode
- Toggle between light and dark theme
- Theme preference saved automatically

### 💾 Data Persistence
- All data saved locally in browser
- Tasks remain after refresh
